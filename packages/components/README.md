# @heyompatil/components

> **Notice**: This is the official alias package for **[`@heyompatil/ui`](https://www.npmjs.com/package/@heyompatil/ui)**.

[![npm version](https://img.shields.io/npm/v/@heyompatil/components.svg?style=flat-square)](https://www.npmjs.com/package/@heyompatil/components)
[![license](https://img.shields.io/npm/l/@heyompatil/components.svg?style=flat-square)](https://github.com/ompatil1906/Portfolio/blob/main/LICENSE)

All components, hooks, and utilities can be installed and imported identically:

```bash
npm install @heyompatil/components
# or
npm install @heyompatil/ui
```

### Usage

```tsx
import { TextFlip, ThemeSwitcher, WheelPicker } from "@heyompatil/components"
```

For full documentation and live interactive demos, visit **[heyompatil.me/components](https://heyompatil.me/components)** or see the flagship package **[`@heyompatil/ui`](https://www.npmjs.com/package/@heyompatil/ui)**.
